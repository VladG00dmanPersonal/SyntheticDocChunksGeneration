# Примеры уставов для синтетической генерации

## Положительные примеры

### Самостоятельные пункты

Законченная мысль, начинается с пункта, заканчивается точкой

```
1.1. Общество с ограниченной ответственностью «Инвестпроект» (далее «Общество») созданов соответствии с Гражданским кодексом Российской Федерации, Федеральным законом «Обобществах с ограниченной ответственностью» и иными правовыми актами действующего законодательства. Настоящая редакция Устава Общества принята на основании решения единственного участника Общества от «25» сентября 2020 г., в соответствии с требованиями действующего законодательства.
```

```
1.2. Полное фирменное наименование Общества на русском языке: Общество с ограниченной ответственностью «Инвестпроект».
```

### Буллеты

Законченная мысль, у каждого пункта есть в начале его родитель, в конце точка или ;

```
6.3. Участник Общества вправе: || - участвовать в управлении делами Общества в порядке, установленном Федеральным законом «Об обществах с ограниченной ответственностью» и уставом Общества;
```

```
6.3. Участник Общества вправе: || - получать информацию о деятельности Общества и знакомиться с его бухгалтерскими книгами и иной документацией в установленном его уставом порядке;
```

```
6.5. Участник общества обязан: || - соблюдать положения настоящего Устава, выполнять решения общего собрания участников Общества;
```

```
6.5. Участник общества обязан: || - не разглашать конфиденциальную информацию о деятельности Общества. Конфиденциальной является любая информация о деятельности Общества, которая стала известна его участнику (в т.ч. информация о заключенных контрактах, выполняемых работах, финансовых результатах деятельности Общества, сведения бухгалтерского учета и др.);
```

### Буллеты второй глубины

```
9.3.К компетенции Общего собрания участников относятся: || 11) утверждение (принятие) документов, регулирующих внутреннюю деятельность Общества, касающихся органов управления Общества (внутренних документов Общества). Положение об Общем собрании участников; || - Положение о Единоличном исполнительном органе – Генеральном директоре;
```

## Отрицательные примеры

Тарабарщина в слове, перевод отдельных токенов на другой язык

```
7.2.3. Имущество, переданное участником Общества в пользование обществу для оплаты своей доли, в случае выхода или исключения такого участника из Общества остается в пользовании Общества в течение срока, на whichй данное имущество было передано.
```

Заголовок как отдельный чанк без смысла, стоит добавить к буллетам

```
8.1. Органы управления Общества

---

К органам управления Общества относятся: || - единственный участник Общества;

---

К органам управления Общества относятся: || - единоличный исполнительный орган – Генеральный директор.
```

Ошибка считывания цифры пункта

```
9.3.К компетенции Общего собрания участников относятся: || 16) назначение ликвидационной комиссии и утверждение ликвидационных балансов;

---

9.3.К компетенции Общего собрания участников относятся: || 7) денежная оценка неденежных вкладов в уставный капитал Общества;
```

```
9:7. Общее собрание участников Общества созывается посредством направления уведомления в адрес участников органом или лицами, созывающими Общее собрание участников Общества, заказным письмом или вручается им лично под расписку, либо - посредством направления графической копии Уведомления по электронной почте, по адресу, указанному участником для направления таких уведомлений. В уведомлении указывается дата, место проведения и повестка дня Общего собрания участников, адрес помещения для ознакомления с информацией и материалами, предоставляемыми участникам. Сообщение должно быть направлено участникам не позднее, чем за 15 дней до даты проведения Общего собрания участников.
```
