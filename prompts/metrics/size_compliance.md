Создай пару только для Size Compliance. Исходный текст обеих версий обязан быть одинаковым:
меняй только границы чанков, не добавляй, не удаляй и не перефразируй текст.

Выбери реалистичный диапазон длины в символах. Все чанки positive должны попадать в него,
а хотя бы один чанк negative — выходить за него. Длину считай как Python `len(chunk)`, включая
пробелы и символы `||`.

Передай выбранный диапазон один раз в evaluation_context:
{
  "evaluation_context": {
    "length_range_chars": {"min": 120, "max": 500}
  }
}
Нарушающий чанк должен однозначно определяться по его фактической длине, без отдельных
индексов в результате.
