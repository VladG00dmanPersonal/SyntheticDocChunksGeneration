Создай пару только для HOPE Information Preservation. Positive должна полностью сохранять
source_document. Это единственное специализированное задание, где negative обязана потерять
или исказить ровно один проверяемый факт; всё остальное сохрани без изменений.

Выбери конкретный факт: срок, условие, исключение, полномочие или ссылку на пункт. Удали либо
минимально искази только его и явно опиши это в controlled_change.

В focus обеих версий используй:
{
  "affected_chunk_indices": [0],
  "fact": "Точная формулировка проверяемого факта из исходного документа"
}
