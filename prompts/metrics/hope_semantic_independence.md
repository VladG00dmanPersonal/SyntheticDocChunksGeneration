Создай пару только для HOPE Semantic Independence. Исходный текст обеих версий обязан быть
одинаковым: меняй только границы/группировку, без потери, добавления и перефразирования.

В positive каждый целевой чанк содержит контекст, необходимый для ответа на вопрос-подсказку.
В negative отдели определение, условие, субъект или ссылку так, чтобы зависимые чанки нельзя
было надёжно понять по отдельности.

Передай вопрос-подсказку один раз в evaluation_context:
{
  "evaluation_context": {
    "cue_question": "Краткий вопрос, для ответа на который нужен отделённый контекст"
  }
}
